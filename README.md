# Portfolio Case Studies

A collection of operational case studies documenting real problems identified,
solutions designed, and outcomes delivered across my career in banking
operations, technology, and process improvement.

These are not theoretical exercises. Each piece documents a situation I
encountered, the approach I took, and what changed as a result - written to
make the work legible to hiring managers who weren't in the room.

---

## Why This Repo Exists

Resumes list what you did. Case studies show how you think.

This repository exists to document the operational and analytical work that
doesn't fit neatly into a bullet point - the process that was broken before
someone mapped it, the program that didn't exist before someone built it, the
fix that scaled further than expected because the root problem was correctly
identified the first time.
